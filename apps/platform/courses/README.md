# 课程目录

保留 plan4 当前课程图谱、章节内容与交互，并以原末幕的三种飞鸟姿态及蓝色线稿作少量动态点缀。全图共九只，分散在不同视野的留白中；章节编号和标签附近自动淡出。

首页长按共鸣后，碎裂直接揭开本页。嵌入时左上角返回原双手场景；单独打开 `index.html` 时返回 `../NOVA.html`。减少动态在嵌入模式由首页统一管理，避免系统偏好覆盖已明确选择的设置。

入场用 3 秒按“纸面与少量线条 → 视野展开与柔焦消退 → 人物和路径 → 章节与导航”渐进呈现，控制器为 `source/awakening.js`。资源预载时保持闭合画面，正常进入才推进目录的同一动画时钟；低可见度期间的控件不接受输入，减少动态下直接显示完整状态。

本目录保存课程构建需要的几何、母图、课程结构、六张配图和六张飞行姿态图片。构建从「奇点」内部的 `source/assets-rebuilt/` 同步鸟素材，不读取外部 plan4 或 concepts 文件夹。请在「奇点」根目录运行 `npm run build` 和 `npm test`。

几何与课程结构的权威输入位于 `source/reference/`，图谱导航位于 `source/navigation.cjs`，交互位于 `source/app.js`，飞鸟动作位于 `source/flock.js`，生成入口为 `source/build.cjs`。运行时保留 `index.html` 与 `assets/` 即可。

课程测试统一位于根目录的 `tests/courses/` 与 `tests/browser/`。目录“我的发现”进入个人账号与成果页；摘要沿用原格式，并按游客/当前账号隔离。公共接入以[个人账号与章节存档接口](../../../../资料-制作过程/整站-迁移前手册/platform/docs/个人账号与章节存档接口.md)为原件。后续开发入口和命令以根目录 `README.md` 为准。

当前目录共13章：发现智能01–04、理解机制05–09、动手创造10–13。第二章为「人工智能的历史」。章节节点与五个视野的导航编号由构建数据生成，维护内容仍从 `source/reference/curriculum.json`、`source/chapter-notes.json` 和 `source/reference/geometry.json` 开始。

第 1–5、7–9 章已经增加正式课程入口，目录旧名称、介绍和小实验保留。使用 `npm run start:linked` 启动主站及已接入的课程；对应关系与返回流程见[课程联动](../../../../资料-制作过程/整站-迁移前手册/platform/docs/课程联动.md)。
