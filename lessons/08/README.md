### 细节修正与本次核验

- 画布按画框内部尺寸布局，统一有图、空框和可点击作品；画框尺寸由实际行列和可用空间计算。移除了旧四图高度上限，解决画布越框与空框尺寸不一。
- 任务标题加大并使用局部衬底，避开前方沙桶；观察板移向右后方并调整角度，机器人移出沙盘侧框，接触阴影跟随所属模型显隐。
- 非沙盘工作页统一木框、纸面、铆钉和表单控件；贝壳使用独立收纳区，并依据沙盘边缘和底栏确定位置，保留清楚的选中状态。
- 区分木尺与条件签按钮栏，条件力度、混合比例不再被标成采样回放；提高夜场页码标签对比度，并排除复选框受到普通输入框样式影响。
- 本次生产构建通过；在当前Edge窗口检查了主沙盘、贝壳工具、配方卡、四图对照、六展位、六幅实际样本及条件签。双图/四图/六图的画框比例与画布边界通过实际DOM检查；没有扩展多尺寸巡查或重走全部25环节。

### 实现与交互

- **实际三维部件**：斜置沙盘、拼接桌板、木框观察板、木牌、画笔筒、刷毛、沙桶、橡皮、木尺与滑柄、机器人和栏杆。Blender 5.2.3 源模型导出GLB，在Three.js中实时渲染；木纹方向、倒角、高光、软阴影、接触阴影和沙粒分别处理。
- **可操作部件**：点击实体画具选择工具；原画可绘制、擦除、撤销；落笔范围随鼠标显示。木柄随真实加噪或采样回放变化。机器人会转头、眨眼，点击可查看当前提示。
- **统一投影**：全景/聚焦切换时，几何、原生按钮和画布一起移动。沙面尺寸及四角来自GLB锚点；DOM投影和指针反解共用单应变换。模型图像仍是实际32×32数据。
- **短引导**：留下一幅原画 → 推动潮水尺 → 查看一个格子 → 自由探索五站。可跳过、回看；引导进度不直接计作学习完成。气泡位置跟随木尺，轮廓高亮避开实际操作。
- **内容层次**：观察板先呈现原图/加噪对照，实际系数与格点值通过按钮展开；明确系数不是相加为100%的占比。采样尺单独标记“采样回放”。不同环节按任务呈现编号、画具或参数工具；多图对照使用独立装裱布局。
- **来源与边界**：环境、五站缩略场景及前景叶片为独立图像素材；没有将A/B/C整页图贴入网页。模型和按钮为独立对象。原有25环节、采样、课程证据和存档格式保留。

| 入口 | 职责 |
