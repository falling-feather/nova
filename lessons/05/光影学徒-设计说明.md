# 第五章《光影学徒》设计说明

更新时间：2026-10-14。状态：已实现并接入主平台；根据验收反馈增加第0关聚焦带练、操作前后知识教学、可定位的实时任务进度，并放大核心操作。实际操作、源码与验证边界见[README.md](README.md)。“光影学徒”为暂用名，章节名称最后统一。

本文件记录 2026-10-05 起讨论确定的第五章新方案：学生用一个上百张、带属性的图片库教一个模型，亲眼看它内部怎样随数据变化，再用没见过的照片检验并纠正。同目录 [README.md](README.md) 中的“学习校准台／温室／小车”方案和 `设计图/` 下的概念图属于早期探索，保留作对照，不再作为实现依据。

## 1 定位

**课程主题**：模型怎样学会：从犯错到调整。

**核心问题**：模型如何从一次错误中作出调整？

**本章要让学生亲手感受到的**：

- 模型“学到的东西”就是它内部的一组数字；训练就是改这些数字，使用（推理）时只读不改。
- 模型判断错了多少，就调整多少；调整只作用于这张照片里出现的线索。
- 给它看什么，它就学会什么，包括你没打算教给它的东西。
- 错误的标签会被认真地学进去；一次调得太猛，模型会被单张照片带跑。
- 检验必须用它没学过的照片；训练好的模型拿去使用时，人和模型各做擅长的部分。

**与相邻章节的分工**：

| 章节 | 学生看到的模型 | 侧重 |
|---|---|---|
| 第三章 森语奇旅 | 黑箱，只能从外面改例子、再试一次 | 标签有依据、例子要多样、改正后要复验 |
| **第五章 光影学徒** | **打开盖子，看见每一次学习改了哪些数字** | **参数、预测、误差、调整幅度、训练与使用** |
| 第六章 | 线索和连接不够用时，需要更复杂的结构 | 神经网络、容量与成本 |
| 第十章 | 学生自己定义问题、采集和划分数据 | 完整的训练、验证与测试项目 |

第三章已经做过“贴标签 → 修例子 → 再学习 → 新照片检验”，本章不重复这条流程。本章的主角是模型内部，让学生看到每一张照片怎样改变它。真实的网络架构留到高中段。

## 2 情境

学校要办“春季自然摄影展”，摄影社收到一百多张投稿，需要按三件事分类：**是不是花朵、是不是以绿色为主、拍得好不好**。社里新来了一个什么都不会的“选片学徒”。学生是策展人，负责教它，最后和它一起把展墙布好。

照片主题延续植物与花，接上第一章“给一朵花拍张照”和第三章的森林。最终成果是一面布好的展墙和一份“学徒学会了什么”的记录。

## 3 美术方向

深色看片桌，中央一块发光的灯箱，与前四章（暖色 3D 小镇、写实博物馆、绘本森林、纸艺棋盘）都不同。

- 照片做成带白边的冲印小样，摆放略有歪斜。
- 天平用黄铜和哑光黑，带仪器质感。
- 三个属性各有固定颜色：花朵是珊瑚粉，绿色是叶绿，拍得好是琥珀黄。“不是”一侧统一用灰色。
- 以 2D 为主，不需要 3D 建模。按初中段“轻表现、重体验”的原则，精力投在反馈手感上：砝码落盘、天平摆动、刻度变化的动效都与真实计算一一对应。

## 4 画面构成：一张俯看的看片桌

保留深色看片桌、发光灯箱、照片小样与黄铜器具。桌面端把观察、判断、核对标签、训练和检验集中在一屏内，按视口高度分配空间，保持核心按钮的实际尺寸。左侧任务／照片、右侧参数／课堂／小票可分别展开和收起；完整说明与列表在侧栏内部滚动。天平下常驻七个参数数值，完整滑杆和学习分量在右侧参数栏，训练讲解时自动展开。顶部给出操作路线，底部保留本关进度与下一步定位。窄屏采用工作区内部纵向滚动，侧栏入口和下一步持续可用。

### 第0关与知识教学

第一次打开新版先进入“摄影社的第一张委托”。聚焦层按正确操作逐步前进：取一张绿叶→插绿色滤片→查证标签→确认“是”→学习一次→观察参数变化→检查三张新照片→回答一句理解检查。背景弱化，只突出当前目标；训练过程中聚焦区域随读线索、预测、核对、调整、再次预测而切换。

带练使用独立的练习模型，沿用真实像素和学习规则，可暂停、刷新续接或重玩。正式五关的参数、照片记录和展墙保持原有进度。完成后回到正式任务，不把带练成绩当作主线模型学会的证据。

正式任务按“导入概念→带着问题操作→对照实际结果解释→关末整理”展开。首次关键操作前出现知识卡，重复同类操作时侧栏持续提供情境说明，避免重复弹窗打断。任务签显示当前/目标数量和总体比例；“本关知识”、操作路线和底部下一步均可直接使用。

| 桌上的物件 | 位置与样子 | 承担的功能 |
|---|---|---|
| 任务签 | 左侧“任务”栏，胶带贴着的纸签 | 本关的问题与 3–4 个目标，完成一项就打勾；“实验笔记”和“完成本关”也在这里 |
| 看片灯箱 | 桌面中央，全画面最亮 | 放大当前照片；检验照片和展览照片会挂上彩带标明身份 |
| 滤片 | 插在灯箱右缘的一排彩色胶片 | 切换“机器的眼睛”；切换时有一道扫描线逐行显出滤片下的画面，对应读数从 0 数到实际值 |
| 读数胶条 | 灯箱下沿 | 6 条线索的读数和小进度条；当前判断有标准线时画出红色刻线（绿色 35%、清晰度 22%、明暗失衡 55%）；点一格看这条线索怎么算 |
| 投稿表 | 胶条下方，带两个装订环的卡片 | 投稿人填的答案、学生教给学徒的答案（是／不是）、“查证”后显示参考答案 |
| 学习铜牌 | 投稿表右侧的绿色铜牌按钮 | 让学徒学这一张；第四关起三种判断一起学 |
| 学徒的天平 | 右上，黄铜天平和刻度盘 | 每条线索一块砝码，大小按“读数 × 信任”；两侧托盘放这张照片里不压秤的线索；刻度盘指出“是”的把握 |
| 信任滑杆 | 右侧“参数”栏，七根竖直的黄铜滑杆；中央常驻数值摘要 | 学徒学到的全部东西；每次学习后显示变化量 |
| 分量旋钮 | 参数栏滑杆下方 | 学习率：轻 0.5、中 1.5、重 6 |
| 投稿抽屉 | 左侧“照片”栏，纸签分批 | 当前批次的全部照片；“成组学”时可多选 |
| 检验盒 | 底部训练按钮右侧的木盒 | 打开后是 2×2 托盘；第五关换成展墙 |
| 学习小票 | 右侧“小票”栏中的打印机 | 每学一次打出一张；可撤销上一次 |

把鼠标移到任一线索上，读数格、天平上的砝码、信任滑杆和账单里的同一行会一起亮起。

## 5 核心循环：放 → 看 → 查 → 学（称、对、调、再称）

1. **放**：从抽屉点一张照片，或拖到灯箱上。
2. **看（机器的眼睛）**：插上“绿色”滤片，扫描线扫过，只有被算作绿色的像素保留颜色；插上“边缘”，只剩轮廓。学生由此明白：学徒眼里的一张照片，只是这几条读数。
3. **查**：投稿表写着投稿人填的答案，学生决定教给学徒“是”还是“不是”。按“查证”只会显示参考答案（绿色和拍得好按影展标准计算，花朵是摄影社的参考），不会替学生改；对不上的行会标红，要学生自己改。
4. **学**：按“让学徒学这一张”，学习过程分五步展开在灯箱下方：
   - **先猜一猜**（每关前两次学习）：六条线索里，哪一条的信任会动得最多？学生点胶条上的一格，也可以跳过。
   - **① 读线索**：六个读数依次亮起，各自乘上信任变成砝码。
   - **② 称一称**：学徒现在的判断和“是”的把握。
   - **③ 对答案**：投稿表上的答案，以及差了多少分。
   - **④ 调信任**：七根滑杆一起移动，下方标出 ↑0.65 这样的变化量。差得越多，调得越多；读数越大的线索，动得越多；读数是 0 的线索一点不动。
   - **⑤ 再称一次**：砝码换位置、变大小，天平重新倾斜，显示“50% → 89%”。最后告诉学生刚才猜得对不对。
   - 每关第三次学习起节奏加快；随时可以“跳过动画”，设置里可以选择“每次都先猜一猜”或“减少动画”。
5. 学过的照片在抽屉里盖“学过”章，按当前判断分别计算；同一张再学会提醒“见过的样子并没有变多”。

## 6 检验盒

开盒后，12 张学徒从没见过的照片按“学徒说 × 答案”落进 2×2 托盘：

|  | 答案是“是” | 答案是“不是” |
|---|---|---|
| 学徒说是 | 说“是”，对了 | 说“是”，认错了 |
| 学徒说不是 | 说“不是”，漏掉了 | 说“不是”，对了 |

- 左侧大字显示“认对 11 / 12”，认错的两格用红边标出；每张照片角上是“是”的把握。
- 自动统计：认错的照片里，压得最重的砝码最常是哪一条（例如第三关常见“红粉占比”，提示学徒可能把“红”当成了花的证据）。全对时提醒再开另一盒，看看是不是碰巧。
- 点任一张照片，盒内右侧显示它的砝码排序；也可以“放到灯箱上细看”，灯箱挂上“检验照片”彩带，学习铜牌换成“转进训练”，旁边有“回到检验盒”。
- 检验照片一旦被学过，就盖“已学过”章，以后不参与计分。
- 可以“换另一盒”。每关两盒，互不重复。

## 6.5 AI 小词典

学生刚体验过的概念，会以“AI 小词典 · 新词”的提示解锁，在顶栏随时翻看。与第三章森语奇旅的小词典用同一种说法：

| 词 | 解锁时机 |
|---|---|
| 特征 | 第一次插滤片或点读数 |
| 参数、训练、误差 | 第一次学习 |
| 测试集、推理 | 第一次打开检验盒 |
| 数据偏差 | 第三关检验盒里出现认错 |
| 标签错误 | 第四关改对一张错签 |
| 学习率 | 轻、重两种分量都用过 |
| 置信度 | 打开展墙 |
| 人机协作、逻辑回归 | 完成第五关 |

## 7 五关

| 关 | 学生的任务 | 关键时刻 | 形成的认识 |
|---|---|---|---|
| 1 先学“绿色” | 挑照片教它；检验认对 10/12 过关 | 几张照片后，“绿色占比”的信任明显升高，“默认倾向”变成负数，两者合起来构成“多绿才算绿”的分界线 | 训练就是改学徒心里的数字；判断时只读这些数字 |
| 2 拍得好吗 | 教它判断照片拍得好不好 | 只看清晰度不够：清晰但太暗的照片仍然不好。“清晰度”压向“是”，“明暗失衡”压向“不是”，两块砝码同时起作用 | 一个判断可以由多条线索共同决定 |
| 3 认出花朵 | 抽屉里先只有“花朵第一批”（红花、粉花、叶子、草地），教完后开检验盒 | 红苹果、红气球被认成花，白花被漏掉。看信任刻度，“红粉占比”被养得很高，原因一目了然。开过检验盒后，第二批投稿才送到 | 你给它看什么，它就学会什么，包括你没打算教给它的东西 |
| 4 纠正与分量 | 新到的投稿表里有人填错了标签；三个属性同时学 | ① 不核对就批量教，系统提示“有 6 张直接用了投稿表上的标签”，天平明显被带歪；② 分量调到“重”，一张怪照片就让天平大幅摆动，原来认对的又认错了 | 错误标签会被认真学进去；学习率太大，会被单张照片带跑 |
| 5 定版布展 | 锁住天平，让学徒给约 30 张照片分区：花朵专区、绿意专区、精选佳作 | 把握在 35%–65% 之间的照片，学徒会举手交给学生决定。展墙标注“学徒自动分了 24 张，你复核了 6 张” | 训练和使用是两件事；人和 AI 分工 |

**结尾钩子**：布展后来了一个新要求：“把有蝴蝶停在上面的花挑出来”。学徒的 6 条线索里没有这个信息，怎么训练都学不会。由此引出第六章：线索和连接不够用，需要更复杂的结构。

## 8 素材与模型规格

### 8.1 图库

训练用照片约 120 张，按批次送达：

| 批次 | 数量 | 内容 | 用于 |
|---|---:|---|---|
| 第一批投稿 | 约 40 | 混合题材，含模糊、过暗、过亮的照片 | 第 1、2 关 |
| 花朵投稿 · 第一批 | 约 24 | 只有红花、粉花、叶子、草地 | 第 3 关的偏差来源 |
| 第二批投稿 | 约 36 | 白花、黄花、紫花、少量绿色的花，红苹果、红气球、白杯子、白云 | 第 3 关开盒后送达 |
| 新到的投稿 | 约 16 | 其中 6 张标签故意填错 | 第 4 关 |

另备：每关 2–3 盒检验照片（每盒 12–16 张，彼此不重复），布展照片约 30 张。

**陷阱照片决定这一章的教学质量**：红色的非花、白色的花、拍糊的花、绿色的花、白云（容易被当作过曝），每类都要有。陷阱不够，学徒就犯不出有教学价值的错误。图库定稿后，要逐张核对线索读数和标签。

### 8.2 线索（学徒能看到的）

| 线索 | 获取方式 |
|---|---|
| 绿色占比 | 浏览器内逐像素统计颜色，真实计算 |
| 红粉占比 | 同上 |
| 白色占比 | 同上 |
| 清晰度 | 取画面中最锐利那部分边缘的强度（如梯度的 99 分位）。拍糊了边缘就软；不按边缘数量算，避免把只有一朵云的天空误判为模糊 |
| 明暗失衡 | 整体亮度偏离适中值的程度，过暗、过亮都会变大 |
| 花形轮廓 | 人工标注，界面上明确标出“标注” |

### 8.3 标签（要学的判断）

花朵、绿色为主、拍得好。每张照片分别存“投稿表上的标签”和“真实答案”，用来支持第 4 关的错填标签。

线索和标签分两层：线索是学徒能看到的读数，标签是要学的答案，答案不写进输入里。

### 8.4 学习规则

每个标签有一组“线索信任值”和一个“默认倾向”，底层是逻辑回归：

- 总分 = 默认倾向 + Σ（线索读数 × 信任）
- 学徒的把握 = 把总分换算到 0–100%（S 形换算，总分 0 对应 50%）
- 每学一张照片：
  - 信任变化 = 分量 ×（正确答案 − 原来的把握）× 这条线索的读数
  - 默认倾向变化 = 分量 ×（正确答案 − 原来的把握）
- 正确答案按“是 = 1、不是 = 0”计算。
- 分量分轻、中、重三档，参考值 0.5 / 1.5 / 6，以试玩手感校准。

学生界面不出现公式和术语推导，只在“它怎么算”的小账单里用加法和百分比呈现。高中段再揭示这就是梯度下降最简单的形式。

## 9 与课程大纲的对应

| 目录中的知识点 | 本章中的对应物 |
|---|---|
| 参数 | 信任刻度与默认倾向 |
| 预测 | 天平给出的判断和把握 |
| 损失／误差 | “差了多少分”，以及检验盒里认对的比例 |
| 学习率 | 一张照片的分量 |
| 训练与推理 | “学这一张”会改刻度；检验和布展只读不改 |

**学科融合**（对应赛事“融合数学、科学、艺术”的要求）：

- 数学：加权求和、百分比、比例与阈值。
- 科学：光与颜色，曝光与清晰度。
- 艺术：摄影的取景与曝光，展览的策划与分区。

## 10 设计原则

- **改标签不等于学过。** 改正投稿表只改记录，按“学这一张”才会调整天平，两个动作在界面上分开。
- **调分量不改变当前判断。** 它只影响之后每次学习的调整幅度，界面上要明确提示。
- **同一张反复学，不等于见过更多样子。** 重复教同一张时给出提示。
- **检验照片一旦学过就不再计分。** 用盖章表示，不静默处理。
- **每一次倾斜都来自真实计算。** 线索从像素算出（标注项除外），判断由当前参数算出，不按图片编号或关卡预设结果，与前四章的真实性原则一致。
- **可撤销。** 学习小票支持撤销上一次学习、清空记忆，鼓励学生大胆试错。
