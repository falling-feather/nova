## 2026-10-28：沉浸式案头工作区

依据 [A 沉浸桌面](../../../资料-界面参考/2026-10-28-第七章减法设计/01-A-沉浸桌面.png)与 [C 双句对照台](../../../资料-界面参考/2026-10-28-第七章减法设计/03-C-双句对照台.png)重构。五间作坊、25个环节与8步核心路线继续使用原有模型和学习记录。

### 界面与场景

- 默认画面直接呈现可操作的案头。顶栏保留返回奇点、游学图、玩法、手记和设置；编辑工具按需展开。原来的“专注桌面”开关被这一默认布局替代。
- 活字有独立字面、凸起字形、铸造接缝与定位缺口。木桌使用实测颜色、法线、粗糙度及环境反射；纸张、斜立纸条、青花笔筒、曲面砚台、线装书与墨辊均为独立三维物件。概念图只用于构图参考。
- 相机微视差、字块抬起/换位、随物体移动的注意力曲线、翻面与印刷墨辊共同构成操作反馈。背景保留浅景深，工作区保持清楚。
- 游学图在当前桌面窗口呈现五间作坊与25个入口。入门引导按作坊出现，关闭后可从“玩法”回看。当前阶段只有一个主要推进按钮。

### 内容与交互

- **铸字房**：按字、按词与模型切分继续使用实际规则；字牌可以拖动重排。
- **名牌馆入门**：先面对六块大活字，点击可来回翻面；背面显示该词真实初始向量的前四个数。完整128维示意按需查看，词义地图与相似度留在后续研究环节。翻面姿态属于界面状态，不替代已经记录的学习观察。
- **议事厅**：句子按阅读顺序排开，保留真正的全句推理。长句使用原有分盘浏览；改变观察词不会打乱排字。连线包含自身权重，拖动与换词后按实际结果更新。
- **上下文对照**：留住原句 → 改线索 → 看变化。两份快照必须对应同一个观察词、同层、同头和不同输入；只明确留样时才替换快照。对照色带使用共同刻度，展示前16维，格差与余弦使用完整128维。已签认的学习证据继续保留。
- **账房**：滑杆保持原节点与焦点，倍率、分配读数和推进按钮同时更新，避免实际计算已变而文字仍旧。
- **排印车间**：候选来自原自回归模型，概率复用统一格式；打印与撤回保持原计算和记录。候选重排后，键盘顺序与下一焦点跟随真实候选顺序；空白稿件的撤回按钮禁用。
- 完整注意力矩阵单独展开。原生弹窗内的操作反馈显示在当前弹窗中，避免落在遮罩后面；返回奇点与其他背景控件一起失去交互并变灰。

默认画质使用九点景深采样与较低分辨率的环境遮蔽/深度通道；工作区设置清晰范围。静止时停止重复绘制，首次光影准备完成后才开放操作。“精细”和“轻量”仍可选择，不宣称跨设备固定帧率。

技术依据来自 Three.js 的 [PBR 材质](https://threejs.org/docs/pages/MeshStandardMaterial.html)、[预过滤环境图](https://threejs.org/docs/pages/PMREMGenerator.html)和 [GTAO](https://threejs.org/docs/pages/GTAOPass.html)文档及当前安装版本的景深源码。既有 Poly Haven 资源继续沿用 [CC0 来源记录](source-assets/pbr.json)。青花竹纹通过内置 image_gen 生成，作为[独立笔筒纹理](public/textures/porcelain-bamboo.png)使用，完整提示词见素材清单。

### 构建与核验

本轮实际环境：Node **24.20.0**、Three.js **0.183.2**、Vite **8.3.0**。

- TypeScript检查与生产构建通过；当前 **68项测试通过**。新增倾斜纸张的几何/DOM对齐检查；原圆桌固定座位断言随已确认设计改为阅读顺序、重排结果及完整注意力权重（含自身连接）。
- 当前 Edge 桌面窗口实际操作：按字/模型切分为10/7块；拖动换序与撤回；折叠编辑台保留草稿；自定义上下文重算与真实 A/B；名牌翻面和完整读数；放大倍率0.25/4.00与分配读数同步；排印保存、撤回和候选焦点；返回奇点目录。
- 示例固定第2层、四头平均，对照“我的苹果屏幕摔裂了。”与“小明吃了一个苹果。”的实际最大格差为 **13.2245**，表示余弦为 **0.6360**。这些是本模型这次输入的读数，不是分类正确率或教学成效。
- 视觉与操作仅针对当前桌面窗口；没有开展手机适配、多尺寸浏览器巡查、全25环节穷举或真实课堂成效验证。
