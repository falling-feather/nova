## 维护命令

先运行npm run build，再以Node 24.20.0或更新版本执行 `node tools/export-frontend.cjs ../nova-windows`。输出目录须不存在，父目录须已存在且在总工作区内；不自动覆盖旧包。当前源码先运行 `npm run build:site`，再以 `npm start` 预览纯前端站点。Windows独立包使用其一键启动脚本。
