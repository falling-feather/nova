# 网页图片与发布体积

2026-11-10 更新。图像策略以 [image-variants.cjs](../tools/image-variants.cjs) 为原件。

## 当前策略

- 首页背景、小镇材质、博物馆高精度彩色贴图、印书局瓷器和问询亭插图使用 WebP 网页版本，保留原始分辨率。透明图片逐像素核对透明度，避免叶片边缘和叠层变化。
- 摄影社的十二张照片图集参与像素特征计算，因此使用无损 WebP，逐像素核对完整 RGBA 数据。图集标识、裁切坐标、标签和学生存档格式不变。
- 噪声图与细线图采用无损编码；已有的 WebP、法线、粗糙度、烘焙遮蔽贴图和模型文件按本轮范围保留。
- 原始美术文件和来源清单保留在源码。整站组装时排除已由网页版本替代的原图；首页只内嵌每个背景的网页版本，避免重复带入原图。

## 修改图片后

```bash
npm run assets:optimize
npm run build:site
```

网页版本已随源码提交，首次克隆只需正常构建。修改原始素材后再执行压缩命令。编码中断时可用 `npm run assets:optimize -- --resume` 继续；已完成文件仍会经过尺寸、透明度和必要的像素核对。

Windows 导出与在线站点使用同一个 [静态组装器](../tools/static-site.cjs)，因此按同一规则筛选发布图片。[部署步骤](deployment.md)。

## 本轮结果

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 本轮处理的 40 张图片 | 109.38 MB | 43.19 MB |
| 首页 `NOVA.html` | 25.98 MB | 8.17 MB |
| 完整静态网站 | 367.05 MB | 296.41 MB |

这里按十进制 MB 统计实际文件大小，不等同于某条网络下的加载时间。首页包含内嵌图片，整站变化同时计入这一部分。

本轮重建主站与第1、2、5、7、9章；40张图片尺寸保持一致，有透明通道的图片透明度一致，十二张教学图集解码像素一致。第5章55项原有测试通过。未改课程算法、模型权重或学习记录。

在桌面 Edge 中检查了首页、小镇、摄影社及博物馆精细画质；摄影社实际显示并读出了原有照片特征。31张独立网页图片的HTTP响应和WebP类型通过检查。没有重走十三章全部学习流程。
